MJArea  ——  面积 / 周长标注 + 红色加粗轮廓
==============================================

命令
----
MJ       主命令，有两种用法：

         (1) 点取区域内部一点（推荐）
             在封闭区域内部点一下，插件自动搜索出该区域的边界（相当于
             自动 -BOUNDARY / BO），然后：
               · 在区域中心写出「面积 / 周长」文字
               · 把该区域复制成一条红色加粗轮廓线
             可以连着点多个区域，全部点完按回车结束。

         (2) 选择已有线框
             在提示处输入 S（或直接回车）后选择线框，可多选、可框选：
               · 若干段直线 / 圆弧端点相接拼成的闭合框（最常用）
               · 闭合多段线（轻量 / 经典）、圆、椭圆、闭合样条
               · 面域、图案填充
             一次选多个区域时，每个区域各生成一处文字 +
             一条红线，最后会问你要不要把「合计」也写到图上。

         文字位置默认在区域中心：先取面积形心；形心落在区域之外
         （例如 C 形、U 形）时会自动改到区域内部的合适位置。

MJA      MJ 的备用名称（作用完全相同）。
MJP      同 MJ，点取内部点的入口，方便单独设快捷键。

MJPLOTQ  快速批量打印：用上次的设置，框选图框后直接出 PDF / 直接打印。
         第一次使用前先运行一次 MJPLOT 做设置。

MJPLOT   批量打印设置向导：
         打印方式 [框选图框(F) / 按布局(L)] → 输出方式 [PDF(P) / 打印机(D)]
         → 打印顺序 → 图框所在空间 → 打印比例 → 纸张尺寸 → 输出设备
         → 输出文件夹 → 文件命名规则。
         图框可以是矩形、闭合多段线，或四段直线围成的矩形。

MJSET    设置：图纸单位、小数位数、文字高度、文字样式、标注格式、
         标注图层 / 颜色、红线图层 / 颜色 / 线宽、加粗方式、
         是否画红线、文字位置、是否标注合计、线宽显示。

MJCLR    清除本插件生成的标注文字 / 红色轮廓（[1] 文字 [2] 红线 [3] 都删）。

PT       瓷砖铺贴（主命令，快捷键 PT = MJTILE）：
         1) 输入 PT 回车；
         2) 在要铺贴的封闭空间内部点一下（自动 BO 出边界，临时边界线自动删除）；
         3) 依次输入 瓷砖长 / 瓷砖宽 / 美缝尺寸（回车 = 用上次的值）；
         4) 再点一下铺贴起点：点在哪里，就有一块整砖的角落在哪里
            （直接回车 = 用第 2 步点房间的那个位置）；
         5) 点完起点立即生成。
         每道砖缝是两条平行线，线间距离 = 美缝尺寸；
         线条自动编组（MJ-瓷砖、MJ-瓷砖-2…），点一条即选中整片。
         输 S = 选已画好的闭合线框；输 M = 进修改菜单。

MJTSET / M
         瓷砖修改菜单：
         [1] 修改已铺贴的瓷砖 —— 点任意一条已铺的砖缝线，
             重新输入砖长/砖宽/美缝/角度，再点新起点（回车=原起点），
             旧线条自动删除并按新参数重画、重新打组。房间轮廓已存在
             插件里，不用重新点房间。
         [2] 修改默认参数 —— 起点偏移、角度、图层、颜色、线宽等。

MJINFO   显示运行信息（插件路径、SECURELOAD、TRUSTEDPATHS 等）+ 内置自检。

MJHELP   显示帮助。

MJTRUST  把插件目录写入 AutoCAD 的「受信任位置」(TRUSTEDPATHS)，
         消除每次启动时的「文件加载 - 安全问题」对话框。

MJUNINSTALL  弹出卸载程序（卸载前会二次确认）。

注意：LI 仍然是 AutoCAD 自带的 LIST（查看对象数据）命令，插件不占用它。

可标注的对象
------------
1) 由多段直线 / 圆弧端点相接拼成的闭合框（最常用）；
2) 闭合多段线（轻量 / 经典）；
3) 圆、椭圆、闭合样条、面域、图案填充。
拼合容差按图形尺寸自动计算（约为对角线的 1/20000），端点差一点点
没接上也能识别；有真正的缺口时会提示「没有拼成闭合的框」。

常用设置说明
------------
图纸单位：毫米（默认，面积显示成 ㎡、周长显示成 m）、厘米、米、不换算。
文字高度：100（安装时统一设定），0 表示自动（按区域大小取对角线 / 22）。
标注格式：支持通配符
          {A} 面积数值 + 单位    {P} 周长数值 + 单位
          {a} 面积数值           {p} 周长数值       {n} 换行
          例如改成一行显示：S={A}  L={P}
红线图层：MJ-面积红线   颜色 1（红）   线宽 0.70 mm
标注图层：MJ-面积标注   颜色 随层
设置保存在 MJArea.ini，下次打开图纸依然有效。

我的工具（工具栏 / 菜单栏）
---------------------------
工具栏：面积周长、批量打印、瓷砖铺贴
瓷砖铺贴快捷键：PT（= MJTILE）  二次修改/默认参数：M 或 MJTSET
菜单栏：面积周长、批量打印、瓷砖铺贴、卸载插件
安装脚本在 AutoCAD 完全退出时写入，重启 AutoCAD 后出现。
